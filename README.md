# Book-Web-scraping

Assignment 2: The Bookstore Intelligence Mission (Business Data and Text Mining).

This Python project collects catalogue data from the educational sandbox [Books to Scrape](https://books.toscrape.com/), turns it into a clean CSV, answers seven business-intelligence questions, and finds the highest combined star-rating score possible within a GBP 100 purchasing budget.

## How to run

Requires Python 3.10 or later.

```bash
pip install -r requirements.txt
python bookstore_scraper.py
```

The default run scrapes the first **5 pages (100 books)**. To scrape the minimum 3 pages, use `python bookstore_scraper.py --pages 3`. To try the bonus boss level, use `python bookstore_scraper.py --all` (50 pages, 1,000 books).

To run the offline tests:

```bash
python -m unittest discover -s tests -v
```

## Output files

| File | Contents |
| --- | --- |
| `competitor_books.csv` | Title, numeric Price (GBP), numeric Rating (1-5), Availability, and product URL |
| `analysis_report.md` | HTML reconnaissance, all seven answers, book recommendation with evidence, budget challenge results, rating counts |
| `ceo_selected_books.csv` | Selected in-stock books for the GBP 100 challenge |
| `rating_distribution.png` | Count of books by star rating |

The scraper generates these files from the actual site; the books are not hardcoded. A GitHub Actions workflow also runs the scraper after a code change and attempts to commit the generated results back to the repository.

## How it works

1. A `requests.Session` downloads the HTML of each catalogue page.
2. BeautifulSoup reads every `article.product_pod` book card.
3. The scraper extracts the `h3 a[title]` book title, `p.price_color` price, `p.star-rating` word rating (One to Five), `p.availability` stock status, and product page URL.
4. A loop handles each page; Pandas removes duplicate URLs and exports a clean dataset.
5. Pandas calculates price extremes, average, 5-star count, in-stock percentage, and the top five rated titles.
6. A 0/1 knapsack dynamic-programming method finds the **maximum combined star-rating points**, with each in-stock book usable at most once and total price no more than GBP 100. Among solutions with the same rating score, it chooses the least expensive total.
7. Matplotlib produces the rating distribution chart.

**Important:** The sandbox website states that its prices and star ratings were randomly assigned. The business recommendation is for practice, not a real-world demand forecast.
